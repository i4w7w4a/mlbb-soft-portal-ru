## Editorial Tone

Русский текст должен быть:

- плотным;
- уверенным;
- без рекламной пены;
- без буквального копирования английского порядка слов;
- понятным игроку MLBB.

Плохой перевод:

> Сдвиньте домашнюю страницу в сторону давления средней линии.

Лучше:

> Сместить главную к давлению на миде и маршрутам через реку.

## Allowed English Exceptions

Эти слова могут оставаться на английском:

- SOFT
- MLBB
- Mobile Legends: Bang Bang
- EXP
- slug/id внутри JSON
- package names
- import paths
- code identifiers
- external URLs

Все остальное требует причины.
