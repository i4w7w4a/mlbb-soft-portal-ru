# Definition of Done

- Public and admin routes build without TypeScript or ESLint errors.
- `npm run content:check` passes on demo content.
- Every hero page has at least one related article and valid SEO metadata.
- `/soft` changes ranking and presentation relative to default mode.
- Search finds heroes, articles, categories, and tags from the typed repository.
- The admin quick editor validates and previews JSON payloads before save.
- Focus rings are visible; mobile layout works at 375px width; reduced motion avoids premium motion effects.
